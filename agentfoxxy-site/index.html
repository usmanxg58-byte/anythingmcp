Quick start

Two commands and it knows your setup

bash 
agentfoxxy setup        # one wizard: model, keys, tools
agentfoxxy              # start talking

agentfoxxy model        # switch AI provider or model
agentfoxxy tools        # turn powers on and off
agentfoxxy gateway      # Telegram / Discord / Slack / WhatsApp / Signal
agentfoxxy -z "..."     # run one job and exit
agentfoxxy update       # update in place
agentfoxxy doctor       # something broken? start here

    FAQ

    Questions, answered

    What is AgentFOXXY?

    A free, open-source AI agent that actually does work. Give it a job in plain words: it plans, codes, runs commands in a real terminal, drives a real browser, reads your files, fixes its own errors and finishes. What it learns is saved as a reusable skill.

    Is it really free?

    Yes — MIT licensed, no subscription, no lock-in. If you connect a paid model provider, that provider bills you; the agent itself is free. You can also run it fully offline against Ollama.

    What do I need installed?

    Python 3.11+ on Linux, macOS or Windows. The one-command installer brings its own Python 3.11, Node.js, ripgrep and ffmpeg, and needs no admin rights. Desktop app users need nothing at all.

    Which AI providers can I use?

    35+ of them: OpenAI, Anthropic, Google Gemini, DeepSeek, Qwen, xAI Grok, AWS Bedrock, Azure OpenAI, OpenRouter, Ollama, Mistral, Cohere, Together AI — and any OpenAI-compatible endpoint. Switch with agentfoxxy model.

    Can I use it from my phone?

    Yes. Run agentfoxxy gateway setup, then gateway start, and message the bot on Telegram, Discord, Slack, WhatsApp or Signal. Same agent, same memory as your terminal.

    What is MCP and why does it matter?

    MCP (Model Context Protocol) is the open standard for connecting agents to tools and data sources. AgentFOXXY speaks it, so any MCP-compatible server can be plugged in to add more powers.

    How does it keep getting better?

    When it solves something hard it saves the method as a skill — 16 built in, plus 21 optional packs covering finance, security, devops, research and writing. You can read, edit, share or delete any skill.

    Is my data safe?

    You choose the provider and the agent talks to it directly, so there is no middleman. It asks before running risky commands. Run it against a local Ollama model and nothing leaves your machine at all.

    Is this related to Hermes Agent?

    Yes. AgentFOXXY is built on the Hermes Agent open-source project; see NOTICE.md for attribution. It is an independent community project and is not affiliated with Nous Research.

    Something is broken — now what?

    Run agentfoxxy doctor first. If that does not solve it, open an issue or a discussion on GitHub and include the output.
